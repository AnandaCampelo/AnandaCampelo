## Selected projects

### [Pine & Dine WEB-POS](https://github.com/AnandaCampelo/web-pos)

A browser-based restaurant point-of-sale interface translated from a supplied mockup into a functional React application.

- Component-based interface with menu filtering, availability states, and reusable UI elements.
- Centralized cart and order state using Redux Toolkit and React Redux.
- Calculated subtotals, tax, and totals, with order submission and order history.

**Stack:** React, Redux Toolkit, React Redux, Vite, CSS

### [Patient Registration](https://github.com/AnandaCampelo/cadastro-pacientes)

A telemedicine frontend coding challenge built from scratch with React and strict TypeScript.

- Layered architecture separating screens, feature logic, services, reusable UI components, and types.
- REST API integration, real-time validation, CPF and date formatting, duplicate-data handling, and clear loading and error states.
- Six automated component tests covering validation and input-formatting behaviour.

**Stack:** React, TypeScript, Vitest, React Testing Library, Vite, Tailwind CSS
